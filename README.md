# MeshLive organisation profile and community files

This repository holds two things for the [MeshLive organisation](https://github.com/MeshLive):

- [`profile/README.md`](profile/README.md), the text shown on the organisation page.
- The default community health files that apply to every MeshLive repository without its own copy: [Contributing](CONTRIBUTING.md), [Security policy](SECURITY.md), [Code of Conduct](CODE_OF_CONDUCT.md), [Support](SUPPORT.md), a [pull request template](.github/PULL_REQUEST_TEMPLATE.md) and [issue forms](.github/ISSUE_TEMPLATE/).

The apps live in [meshlive-android](https://github.com/MeshLive/meshlive-android), [meshlive-windows](https://github.com/MeshLive/meshlive-windows) and [meshlive-apple](https://github.com/MeshLive/meshlive-apple) (iPhone and Mac). Measured results are in [meshlive-benchmarks](https://github.com/MeshLive/meshlive-benchmarks), and the website is [meshlive.github.io](https://meshlive.github.io).

Edit the platform table in the profile whenever a platform's status changes, and keep it consistent with each repository's README.
