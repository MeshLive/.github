# MeshLive

Live video, voice calls and messages between nearby phones, over Bluetooth, with no internet.

MeshLive is free and open-source software (GPL-3.0-or-later). Phones talk directly to each other and can relay a live stream through other nearby phones, with end-to-end encryption, so it keeps working off-grid, in emergencies, or where the internet is down or censored.

- **[meshlive-android](https://github.com/MeshLive/meshlive-android)**: the Android app (canonical): protocol, test vectors and tools
- **[meshlive-benchmarks](https://github.com/MeshLive/meshlive-benchmarks)**: measured results on real phones, a baseline to compare against
- **[meshlive-ios](https://github.com/MeshLive/meshlive-ios)**: the iPhone app (early, interoperable with Android)

Status: public beta. Expect rough edges, and please report what you find.
